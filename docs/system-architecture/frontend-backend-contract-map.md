# Frontend–backend contract map

| Frontend function | Method | Requested URL | Backend handler | Request compatibility | Response compatibility | Status |
|---|---|---|---|---|---|---|
| native login form | POST | `/login` | `process_login` | form fields accepted | HTML error or 303 + cookie handled by browser | Matched |
| `startBadgePolling` | GET | dynamic `data-badge-url` | route depends on rendered value | URL generated by server templates | JSON count expected | Partially matched |
| `renderPreviewPages` | GET | `/api/v1/documents/{id}/preview?page=N` | `preview_document` | path/query and cookie auth match | streamed PNG loads as `<img>` | Matched |
| document download link | GET | `/api/v1/documents/{id}/download` | `download_document` | path and cookie auth match | signed redirect handled by browser | Matched |
| upload XHR/native form | POST | `/applications/{id}/documents/upload` | `upload_document` | multipart `UploadFile` + form category | 303/navigation handling matches | Matched |
| wizard native submit | POST | `/applications/{id}/step/{step}` | `save_application_step` | form/path fields handled per step | 303 next step | Matched |
| wizard draft fetch | POST | form action + `?draft=1` | `save_application_step` | form body and draft query supported by route logic | response redirect/history behavior is handled | Matched |
| branch checklist toggle | POST | `/applications/{id}/checklist` | `update_checklist` | JSON/body handling confirmed in route | client handles failure | Matched |
| invitation submit | POST | `/api/v1/users/invitations` | `create_invitation` | JSON fields map to invitation input | JSON message/email_sent used | Matched |
| role save | PUT | `/api/v1/users/{id}/role` | `update_user_role` | `{role}` matches `UserRoleUpdate` | JSON success used only to reload | Matched |
| deactivate | POST | `/api/v1/users/{id}/deactivate` | `deactivate_user` | path only | JSON success then reload | Matched |
| share-link generation | POST | `/loans/generate-share-link` | `generate_share_link` | same-origin authenticated action | JSON link consumed | Matched |
| client link generation | POST | `/applications/{id}/client-link` | `generate_existing_client_link` | path/cookie match | JSON link consumed | Matched |
| guarantor link generation | POST | `/applications/{id}/guarantor-link/{slot}` | none | no declared route | no backend response contract | Backend endpoint not found |
| signing viewed | POST | `/client-form/signing/viewed` | `record_signing_viewed` | client-session cookie dependency | response does not drive complex UI | Matched |
| OTP start | POST | `/client-form/signing/otp/start` | `start_signing_otp` | client-session cookie | JSON status consumed | Matched |
| OTP verify | POST | `/client-form/signing/otp/verify` | `verify_signing_otp` | JSON/form body handled by route | JSON verification state consumed | Matched |
| guarantor signature form | POST | `/client-form/apply/guarantors/sign` | none | no declared route | completion impossible | Backend endpoint not found |
| native search | GET | `/search?q=...` | `search` | query matches | HTML results | Matched |
| role workflow forms | POST | rendered `/applications/{id}/...` actions | corresponding loan-router handlers | native form contracts route-specific | 303/template error | Matched |

`startBadgePolling` is partial because its concrete URLs are data-driven at render time; each rendered page must be exercised to verify the JSON shape. Native forms are not duplicated row-by-row here; the exhaustive route family is listed in `route-map.md`, and their actions are server-generated.
